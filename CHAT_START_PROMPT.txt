Attached/available: reference video. Ultra is zero-install, offline, zero-API. No npm install, no AI APIs, no internet.

1. Primary: `git clone https://github.com/akspro9866-art/ultra-workflow ultra-workflow && node ultra-workflow/dist/ultra.mjs doctor --json`. Fallback (no GitHub): unzip ultra-workflow-cloud.zip → `node ultra/ultra.mjs doctor --json`. Then read SKILL.md and follow it exactly.
2. `probe <my-reference.mp4>` — inspect probe.json (cuts, per-scene palettes, luminance/contrast, audio-envelope beats) and every contact sheet + probe frame natively with your vision.
3. Write workspace/DESIGN.md (measured palette/type/texture), Motion.md, ultra.json. Use primitives (reveal/camera/clipReveal/svgDraw/motionBlurSamples). For exotic shots author workspace/scenes/<name>.html with window.ultraRender(frame,fps,t,progress,audio) + window.UltraEase via "customHtmlFile". Vector scenes: engine "revideo" + enginePayload.sceneType vectors/chart/counter/code. Then `validate-spec`.
4. `asset-plan` → generate EVERY listed asset natively to its targetPath → `validate-assets`.
5. `build`, then `verify <my-reference.mp4>`: inspect EVERY build/audit-frames/pair_*.png, SSIM sceneSimilarity[] and verify-report.json; score the 100-point rubric. Any critical defect, score < 90, or stutterEvents > 0 → workspace/patch.json → `patch`, `build`, `verify` (max 3 rounds).
6. Only when verification passes: `render`, then deliver build/ultra-final.mp4 with rubric scores, engine table and patch history. Enforce the anti-slop checklist in SKILL.md (reference palette only, no Arial/Times defaults, no neon-purple AI gradients, real easing, stutterEvents 0).
