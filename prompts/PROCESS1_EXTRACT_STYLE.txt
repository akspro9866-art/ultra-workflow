PROCESS 1 — EXTRACT STYLE (1–10 reference videos → downloadable Style Pack)

Attached: 1–10 reference videos. Ultra is zero-install, offline, zero-API: https://github.com/akspro9866-art/ultra-workflow

1. Boot (no npm install): `git clone https://github.com/akspro9866-art/ultra-workflow ultra-workflow && node ultra-workflow/dist/ultra.mjs doctor --json`. Set ULTRA="node ultra-workflow/dist/ultra.mjs".
2. Run: `$ULTRA style-probe <ref1.mp4> ... <refN.mp4> --out workspace/style-probe --hook-window <hookWindowSec>`.
3. Natively inspect workspace/style-probe/aggregate.json, batch-overview.png, every ref-XX/contact-sheet-*.png and candidates/*.png. Do a Map-Reduce across all 8 groups from aggregate data: Pacing & Cut Grammar, Camera & Motion Physics, Typography & Captions, A-Roll/B-Roll Visual Layering, Color Grade & Texture Stack, Transition Vocabulary, Sound Design & Mix DNA, Hook & Narrative Structure.
4. Pick 4–6 clean candidate stills per reference into your pack `exemplars/` (2–8 total). Author a deterministic offline motif (motifs/*.html) that uses `window.__ULTRA_SEEK`; no CDN scripts.
5. Write a pack directory `<slug>/` containing: `style.json` matching the strict schema in `core/style-schema.ts` (all 8 groups, real measured values — no generic guesses), `STYLE.md` (≥300 chars, cite the measurements), `exemplars/`, `motifs/`, optional `grade.cube` (only if referenced by `colorAndTexture.lutFile`) and signature `assets/`. Slug must be lowercase-dashed (e.g., `punchy-tech`).
6. Validate until exit 0: `$ULTRA style-validate <slug>`.
7. Package for download: `$ULTRA style-export <slug> --out build/<slug>-style-pack.zip`.
8. Deliver the single `.zip` plus a summary table: slug, referenceCount, ASL hook/body/outro, maxStaticHoldSec, beatSnapRatio, palette hexes, motifs, exemplars. The user will download it and import it in Qoder with prompts/QODER_IMPORT_STYLE_TO_REPO.txt. Never skip style-validate or style-export.

V5 STUDIO COMMANDS (use these — do not guess state):
- `status --json`: call at chat start and after every long step; returns detected process, completed stages, pending assets, draft/verify state and the exact `nextCommand`.
- `captions-align --srt <file> | --vtt <file> | --words <file> | --script <file> --envelope <audio-envelope.json>` with `--style <slug> --aspect 9:16|16:9|1:1 --out workspace/captions.json`: word-level chunks, keyword flags and safeBox; sourceClip scenes ingest it automatically as active-word pill/underline/color captions.
- `--aspect 9:16|16:9|1:1` also applies to `raw-probe` and `meta.aspectProfile`; 9:16 reserves top 12% / bottom 22% / right 15% / left 5%. Rule 5 lint flags captions or text inside platform danger zones.
- Built-in Style Packs ready now: `punchy-shortform` (9:16), `kinetic-editorial` (16:9), `dark-tech-launch` (16:9). Use with `--style <slug>`; use their style.json/STYLE.md/motifs as gold-standard structure in Process 1.
- Bundled offline fonts: Ultra Display / Ultra Sans / Ultra Mono (`assets/fonts/*.ttf`) — never download fonts.
- `ULTRA_FORCE_TIER=full-cdp|browserless-py|ffmpeg-only` forces a render tier for deterministic debugging (ffmpeg-only is pure FFmpeg with bundled TTFs).
- Linux CI badge: https://github.com/akspro9866-art/ultra-workflow/actions/workflows/ci.yml/badge.svg

V6 PRE-PRODUCTION GATE (mandatory before ANY build/verify/render):
1. `plan-init [--mode clone|edit-in-style] [--style <slug>] [--aspect 16:9|9:16|1:1] [--resolution 4k|1080p]` then fill the real concept/palette/typography/storyboard in workspace/plan.json.
2. `preprod-render` -> build/preprod/moodboard.png + storyboard*.png. Show BOTH to the user and WAIT for explicit approval; only then run `approve --by user`. Build/render are hard-blocked on a matching planHash.
3. After approval: assets -> `build --proxy` -> `verify` / `ralph auto-fix` (stutterEvents 0, lint pass, score >= 90).
4. Master: `render --4k` (default hybrid; strategy logged in delivery-manifest.json) -> `export-project` (FCPXML 1.10 + OTIO + project.ultra.json + offline index.html + CRC-verified zip) -> `guard --stage delivery` must exit 0.
V6 tools: `context-pack --stage preprod|assets|build|verify|fix|master --budget-tokens 3500`, `rag query "<query>" [--kind style|motif|sfx|rule|skill|effect] [--aspect ...]`, `orchestrate --status [--json]`, `ralph init|auto-fix|status`, `guard --stage plan|build|verify|delivery [--json]`.
