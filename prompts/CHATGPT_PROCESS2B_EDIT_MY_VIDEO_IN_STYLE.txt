CHATGPT · PROCESS 2B — EDIT MY RAW VIDEO IN AN INSTALLED STYLE

Repo: https://github.com/akspro9866-art/ultra-workflow · Zero-install/offline/zero-API: `curl -L -o ultra-workflow-cloud.zip https://raw.githubusercontent.com/akspro9866-art/ultra-workflow/main/dist/ultra-workflow-cloud.zip` (or upload the zip), `unzip -q ultra-workflow-cloud.zip -d ultra`, `node ultra/ultra.mjs doctor --json --host chatgpt`.

1. `node ultra/ultra.mjs style-list` → pick `--style <slug>` (packs ship in ultra/styles/; import new ones in Qoder with prompts/QODER_IMPORT_STYLE_TO_REPO.txt).
2. Upload my_video.mp4; run `node ultra/ultra.mjs raw-probe my_video.mp4 --style <slug> --out workspace/raw-probe`. Inspect raw-edit-plan.json: silences/dead air, keepSegments, hookEnd, targetBodyAslSec, maxStaticHoldSec, punchInPoints, brollCutaways, captionWindows.
3. Author ultra.json from the plan: sourceClip scenes `{path,inSec,outSec,jCutLeadSec,lCutTrailSec,cropMode}`; punch-in via camera keyframes; styled captions (style palette/casing/word highlight); motif/B-roll overlays per plan; only allowed transitions (never bannedTypes); style colorGrade + grain. `validate-spec`.
4. `asset-plan --host chatgpt` for any overlays; use Image Generation for stills; `synth-audio` for any extra SFX/music; `validate-assets`.
5. `build` → `verify --style <slug>`: require stutterEvents 0, ±1.5 dB style LUFS, style compliance all OK, and inspect build/audit-frames/style-match.png (STYLE EXEMPLAR vs YOUR EDIT). Grade 0–100; patch via workspace/patch.json + `patch`/`build`/`verify` (≤3 rounds) until ≥90.
6. `render`; deliver build/ultra-final.mp4 + compliance block + match score + patch history.

V5 STUDIO COMMANDS (use these — do not guess state):
- `status --json`: call at chat start and after every long step; returns detected process, completed stages, pending assets, draft/verify state and the exact `nextCommand`.
- `captions-align --srt <file> | --vtt <file> | --words <file> | --script <file> --envelope <audio-envelope.json>` with `--style <slug> --aspect 9:16|16:9|1:1 --out workspace/captions.json`: word-level chunks, keyword flags and safeBox; sourceClip scenes ingest it automatically as active-word pill/underline/color captions.
- `--aspect 9:16|16:9|1:1` also applies to `raw-probe` and `meta.aspectProfile`; 9:16 reserves top 12% / bottom 22% / right 15% / left 5%. Rule 5 lint flags captions or text inside platform danger zones.
- Built-in Style Packs ready now: `punchy-shortform` (9:16), `kinetic-editorial` (16:9), `dark-tech-launch` (16:9). Use with `--style <slug>`; use their style.json/STYLE.md/motifs as gold-standard structure in Process 1.
- Bundled offline fonts: Ultra Display / Ultra Sans / Ultra Mono (`assets/fonts/*.ttf`) — never download fonts.
- `ULTRA_FORCE_TIER=full-cdp|browserless-py|ffmpeg-only` forces a render tier for deterministic debugging (ffmpeg-only is pure FFmpeg with bundled TTFs).
