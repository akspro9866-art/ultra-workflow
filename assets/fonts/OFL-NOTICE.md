# Bundled offline fonts

These TTFs are subset, single-weight builds generated by `scripts/make-bundled-fonts.py`
from open-license variable font sources. They travel inside `dist/ultra-workflow-cloud.zip`
so browserless ChatGPT/Linux containers render agency-grade type with no network access.

| File | Family | Source | License |
| --- | --- | --- | --- |
| UltraDisplay-Bold.ttf | Ultra Display (Space Grotesk 700) | https://github.com/floriankarsten/space-grotesk | SIL Open Font License 1.1 |
| UltraSans-Regular.ttf | Ultra Sans (Inter 400) | https://github.com/rsms/inter | SIL Open Font License 1.1 |
| UltraSans-Bold.ttf | Ultra Sans (Inter 700) | https://github.com/rsms/inter | SIL Open Font License 1.1 |
| UltraMono-Regular.ttf | Ultra Mono (JetBrains Mono 400) | https://github.com/JetBrains/JetBrainsMono | SIL Open Font License 1.1 |

Each source family is distributed under the SIL Open Font License, Version 1.1
(https://openfontlicense.org). The generated files are renamed to `Ultra *` families
and subset to Latin, typographic punctuation and the symbols used by captions.
No proprietary fonts are bundled.
