# DESIGN — A New System / Familiar / Adaptable / Intentional / Human

## Reference read
The supplied 8.958 s, 702×396, 24 fps clip is an abstract editorial design film. It is not a worship-room walkthrough despite the download filename. The actual frames carry five text beats: **a new system → that feels → familiar → adaptable → intentional → and → human**.

## Visual language
- Canvas: 960×540 native render, 16:9, 24 fps.
- Base colors: dusty blush, paper, graphite, acid-lime, muted lilac and ice blue.
- Typography: bundled UltraDisplay / UltraSans; light, widely tracked display words; avoid heavy all-caps except the first NEW beat.
- Imagery: separately extracted image crops (keyboard, fabric, face, coastal water, outdoor portrait, iridescent surface, eye, blue ripple, flower, clouds, field portrait, hands, grasses and people/sky detail). Each crop becomes an independent media layer.
- Motifs: three pale circles, a wire globe card, small color fragments, elliptical apertures and a single dark pebble counter-shape.

## Design constraints
No complete reference frame is used as a background plate. Only isolated photo tiles are reused from the supplied reference itself so the image content remains true to the source. Every image tile is timed and positioned independently; text, shapes, photo masks, transitions and sound are composed separately.
